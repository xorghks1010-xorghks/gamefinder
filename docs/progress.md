## 7차: 임팩트 모션 (포트폴리오용으로 단조로워 보여서 추가)

- **Hero**: 마우스 움직임에 배경 이미지·장식(궤도/SALE·TOP 글자)·텍스트가 서로 다른 속도로 움직이는 시차 + 커서를 따라다니는 은은한 빛
- **카드**: 인기/최신/대표할인 카드가 마우스 위치에 따라 기울어지고(최대 4~7도) 빛이 반사됨. 가로형 할인 카드는 제외
- **스크롤**: 섹션이 보이면 카드가 90ms 간격으로 순서대로 올라오며 등장
- **숫자**: 대표 할인 카드의 `-50%`가 0부터 올라감 (0.9초)
- 마우스 전용(`hover:hover` + `pointer:fine`)이고 `prefers-reduced-motion` 이면 모두 꺼짐 → 터치 기기·모션 줄이기에서는 기존 화면 그대로
- 검증: Chrome 원격제어로 실제 마우스 이동 → `--px`, 틸트 `--rx/--ry`, 카운트업(-33% → -50%) 값 확인, 1440px/390px 레이아웃 확인

## 9차: 전체 다크 톤

- `base.css` 색 토큰을 다크로 교체: `--bg #0a1222`, `--bg-alt #0e1a35`(교차 섹션), `--bg-soft #111f3f`(카드·타일·칩 면), `--text #e8edf7`, `--heading #f4f7fd`(새로 추가, 제목용), `--muted #9aa7c0`, `--line #26345a`, `color-scheme: dark`
- 주의: `--navy`는 이제 **배경용**(카드 media 배경, 알림, 할인 배지 등)으로만 쓰고, 제목 글자색은 `--heading`을 씀
- 개별 수정: 가로형 할인 카드(흰 → `--bg-soft`), 탐색 타일·장르 칩·호버(네이비 → 블루), 알림(`.gf-notice`), 할인 섹션 점 패턴(흰색 점), Epic Games 점 색, 섹션 라벨(`--blue` 3.96:1 → `--blue-soft` 9.5:1)
- 검증: 데스크톱 1440px 전체 / 모바일 390px 캡처 확인, 대비 계산(보조 글자 6.7:1 이상)
- 안 건드림: Hero, AI 섹션, 헤더, 푸터(원래 다크). 백업 `gamefinder-backup-2026-11-15/`는 **다크 톤 변경 직전**(모션·AI 데모 포함) 버전이라 되돌리고 싶으면 이걸로 복원
- 후속 확인 완료(2026-11-15): 오류(`?mock=error`)·빈(`?mock=empty`) 상태 화면, 실제 CheapShark 데이터 화면 모두 다크 톤에서 정상. 오류 화면 '다시 시도' 버튼 글자는 `--blue-soft`로, 일반 카드 호버 제목색도 `--blue-soft`로 수정. 포커스 링도 `--blue-soft`. (실제 키보드 이동은 아직 수동 확인 전)

## 8차: AI 섹션 인터랙티브 데모

- 취향 문구 3개(`스토리가 탄탄한 RPG` / `혼자 즐기는 힐링 게임` / `친구와 함께하는 협동 액션`)를 `<button aria-pressed>`로 변경. 누르면 0.65초 "취향을 분석하는 중…" 후 예시 추천 3개(커버·제목·추천 이유) 표시, 같은 칩을 다시 누르면 해제. 처음엔 첫 번째 칩이 선택된 상태
- **실제 AI 호출 아님**: 칩별 게임 3개와 이유는 `ai-intro.js`의 `DEMOS`에 하드코딩, 게임 정보는 `data/mock/games.js`에서 id로 조회. 화면에 "예시 미리보기" 배지 + 안내 문구 표시. 적합도 점수는 만들지 않음
- 선택 상태는 색뿐 아니라 ✓ 표시·굵기로도 구분, 결과 영역 `aria-live="polite"`, 모션 줄이기 시 분석 연출 생략
- 기획서 `plan.md` 04-3 AI 추천 소개 행의 "클릭 기능 추가하지 않음"을 위 내용으로 수정함
- 검증: Chrome 원격제어로 실제 클릭 → 선택/분석중/결과/해제 상태와 JS 오류 없음 확인, 1440px·390px 화면 확인
- 나중에 할 일: 실제 AI 추천 페이지(`#/ai`)를 만들면 이 데모의 문구·결과와 톤을 맞출 것. 추천 이유 문구는 직접 쓴 예시이니 필요하면 수정

## 23차: 게임 찾기 페이지 `#/find` + 게임 카탈로그 (2026-11-19, 커밋 전 — 22차까지 중 21차는 `125025d` 로컬 커밋, 22·23차는 미커밋, 전부 배포 전)

- **화면**: 장르(**여러 개 선택, 같은 그룹은 OR**) · 플레이 방식(싱글플레이/멀티플레이/협동/PvP, 여러 개 선택 OR) · 가격(전체/무료/유료) 칩 + 게임명 키워드 + 정렬(인기순=리뷰 많은 순 / 평점순=Metacritic / 최신순 / 이름순) + 24개씩 더 보기. **서로 다른 그룹은 AND**(기획서 규칙). 개수는 **"게임 전체 172개 중 24개 표시 · 기준일 2026.11.18"**. 결과는 `result` 카드(커버·출처·제목·'장르 · 출시연도 · Steam 리뷰 수'·오른쪽 '무료'/Metacritic 점수). 필터 상태는 주소에 저장(`#/find?genre=rpg,action&mode=coop&price=free&sort=score&q=...`), 상세 갔다 오면 복원, 결과 없으면 '필터 초기화'
- **데이터 = 미리 받아 둔 카탈로그**: CheapShark 는 장르를 주지 않고 Steam API 는 CORS 로 못 읽어서 → **`scripts/fetch-catalog.mjs`**(`node scripts/fetch-catalog.mjs`)가 후보 게임의 Steam `appdetails`(장르·`categories`→플레이 방식·출시일·Metacritic·리뷰 수·무료 여부)를 받아 **`data/catalog/games.js`**(사이트가 `<script>` 로 읽음, 약 100KB, 583개 — 처음엔 `games.json` 이었으나 file:// 문제로 변경)에 저장. **`known.json`** 은 다음 실행에서 이미 받은 게임을 건너뛰기 위한 내부 캐시(사이트는 안 읽음). 후보 = 인기 차트 + CheapShark Metacritic 상위 8페이지 + 국내 선정작 + `data/steam` = 584개. **처음 한 번 약 17분**(요청 사이 1.7초), 이후엔 30일 지난 게임·새 게임만 받음. 속도 제한(429)이면 60초 대기, 25개마다 저장해서 끊겨도 이어서 받음. 게임이 아닌 항목(DLC·소프트웨어)·정보 없음 1개 제외
- **장르 분포**(Steam 기준): Action 331 / Adventure 274 / Indie 263 / RPG 172 / Strategy 104 / Simulation 93 / Casual 67 / MMO 23 / Sports 17 / Racing 11. 플레이 방식: 싱글 547 / 멀티 220 / 협동 150 / PvP 113. 무료 36, Metacritic 있음 409. 장르 없음 4·출시일 없음 1
- **목록 페이지 공통 컴포넌트 확장 (`list-page.js`)**: `groups`(칩 그룹 여러 개, `multi`·`title`), `unsupported(params)`(못 다루는 필터면 목록 대신 이유 표시), 응답의 `total`('전체 N개 중 M개'). 기존 `chips` 줄임 표기는 그대로 동작(할인·신작·순위·검색 회귀 검증 통과). 파일 맨 위 주석에 설정 설명 정리됨
- **메인 '플랫폼·장르 탐색' 타일 연결**: 장르 id 가 Steam 장르와 맞는 것(rpg·action·strategy·adventure·simulation·sports·racing)은 필터가 걸림. **데이터가 없는 것은 이유를 안내**: `?genre=horror|fps|puzzle`(Steam 장르가 아니라 사용자 태그라 없음), `?platform=ps5|xbox|switch2`(PC 데이터만 있음) → '‘Horror’ 장르는 아직 제공하지 않아요' / '현재는 PC(Steam) 게임 데이터만 제공해서 PlayStation 5 게임은 찾을 수 없어요' + '전체 게임 보기' 버튼. `?platform=pc` 는 전체 목록. (타일을 지우거나 SteamSpy 태그로 공포·FPS·퍼즐을 채우는 건 나중에 결정)
- **갱신 방법**: `node scripts/fetch-catalog.mjs` 후 `data/catalog` 커밋·배포. 자동 갱신 워크플로(`.github/workflows/update-steam-data.yml`)에 카탈로그 단계를 추가해 뒀지만 그 파일은 토큰 권한 문제로 아직 미커밋
- **한계**: 전체 게임이 아니라 **인기 PC 게임 약 600개**(하단 안내문에 명시). 영어 이름 키워드만(한글 이름 검색은 보류 — 22차 참고). 가격은 카탈로그에 없음(무료 여부만). 플랫폼 필터 없음. 장르는 Steam 기준이라 '공포'·'FPS'·'퍼즐' 없음. 오래된 정보는 기준일 표시로 알림
- **검증 (Chrome CDP, 전체 583개)**: 기본 '전체 583개 중 24개'·끝까지 더 보기 **583개 중복 0**·다중 선택 OR(RPG 172, RPG+Action 412)·AND(RPG+협동 45, 스포츠+무료 2, 유료+PvP 91)·**브라우저 표시 개수가 파일을 직접 계산한 값과 8개 조합 모두 일치**·정렬 4종·키워드(`ELDEN` 1개)·결과 없음+초기화·잘못된 쿼리 보정·메인 타일(`platform=ps5`·`genre=horror` 안내, `platform=pc`·`genre=rpg` 정상)·카드 클릭→상세→뒤로가기 복원·`?mock=1`·1440/375px 가로 넘침 없음·JS 오류 없음. 할인 모바일 칩이 한 줄 유지되는지도 회귀 확인

## 22차: 검색 페이지 `#/search` (2026-11-19, 커밋 전 — 21차까지는 `125025d` 로컬 커밋, 배포 전)

- **흐름**: 헤더 검색창에서 제출 → `#/search?q=<검색어>` (헤더가 원래 쓰던 `routes.searchHref`). 검색 페이지 안에도 검색창이 있음(모바일 편의). 어느 쪽으로 검색해도 두 입력창이 같은 검색어를 보여줌(헤더는 `header.js` `onRoute`에서 동기화). 검색어가 없으면 요청 없이 안내 문구. 문서 제목 '‘elden’ 검색 — GameFinder'. 결과는 20개씩 더 보기
- **파일**: `game-service.js`(`searchAll`·`getSearchList(q, offset)`), `game-card.js`(`result` 카드), `list-page.js`에 **검색어 지원 추가**(`cfg.query`, `descFor`, `docTitleFor`, `empty`를 함수로, 빈 검색어 안내), `page-configs.js`(`search` 설정), `route-notice.js`(검색 시 '준비 중' 안내 제거), `header.js`, CSS
- **세 곳을 함께 검색해서 합침**: ① **CheapShark 제목 검색**(`/deals?title=&storeID=1,25&pageSize=60`, 같은 게임은 가장 싼 스토어 한 줄) ② **Steam 인기 차트의 이름**(CS2·Dota 2 같은 **무료 게임은 CheapShark에 없어서** 차트에서 찾음) ③ **FreeToGame**(무료 온라인 게임, 국내 게임 포함). 제목·Steam appid 로 중복 제거. 결과는 `searchCache`에 보관(더 보기·재방문 때 재요청 없음)
- **CheapShark 제목 검색의 함정 (실측)**: 단어 **중간까지 일치**(`elden` → `Hirschfelden`), **한글처럼 못 찾는 검색어엔 엉뚱한 목록**을 돌려줌 → **제목에 검색어(정규화)가 실제로 들어간 것만** 남기고 **관련도순** 정렬: 0 정확히 같음 / 1 제목이 검색어로 시작 / 2 단어가 검색어로 시작 / 3 단어 중간 포함, 같으면 리뷰 수·접속자 많은 순. (예: `elden` → ELDEN RING, NIGHTREIGN, Elden Gunfire 2 … / `dota` → Dota 2, Dotage, Dota Underlords …)
- **한글 검색은 일부만**: 게임 이름이 전부 영어라 한글로는 못 찾음. 단 **편집 선정 국내 인기작 5개**는 한글 별칭(`KR_ALIASES`: 배틀그라운드·배그, 로스트아크·로아, 검은사막, 메이플스토리·메이플, 던전앤파이터·던파)으로 찾음 — 별칭을 늘리려면 `KR_ALIASES`에 추가. 결과 없음 문구와 하단 안내문에 "영어 이름으로 검색" 명시

  - `scripts/fetch-steam.mjs`(Node 18+, 패키지 없음): CheapShark 인기 12·최신 12·할인 10 + 편집 선정 국내 5개 = 약 39개를 `l=koreana&cc=kr`로 받아 `data/steam/<appId>.json`(+`index.json`)에 저장. 요청 사이 1.5초 대기, 실패는 건너뜀, 대상에서 빠진 파일은 삭제. 저장 항목: 이름·설명(`descLang` ko/en)·장르·개발사·퍼블리셔·스크린샷(thumb/full 8장)·최소 요구사항(항목명 한국어)·한국어 지원 여부
  - **실행 결과**: 39개 중 35개 저장(약 209KB). **로스트아크·검은사막·메이플스토리·던전앤파이터는 Steam이 한국 지역에서 정보를 주지 않아 파일 없음**(한국 퍼블리셔 직접 서비스) → 직접 쓴 한국어 소개로 대체
  - `game-service.js`: `getSteamStatic(appId)`로 파일을 읽음. **없으면 예전 방식으로 그대로 표시**(안전). 소개 우선순위 = 직접 쓴 한국어 > Steam 설명(한국어/영문) > FreeToGame 영문. 스크린샷·개발사·퍼블리셔·요구사항·장르도 Steam 데이터 우선, 스크린샷은 `{thumb, full}` 형태로 통일
  - `game-detail.js`: 소개 출처 문구 세분화(직접 작성 / Steam 한국어 / Steam 영문 / FreeToGame), 영문이면 번역 버튼, 게임 정보에 '한국어 지원' 행, **Steam 스토어 위젯은 맨 아래로**('Steam 스토어')
  - `.github/workflows/update-steam-data.yml`: 매일 04:17(KST) 자동 실행 + 수동 실행 가능, 변경되면 `data/steam`만 커밋·push
- 결과 예: Baldur's Gate 3(영문 소개+번역 버튼, 스크린샷 8, 요구사항 7), ELDEN RING(한국어 소개), PUBG(직접 쓴 소개+Steam 스크린샷)
- **자동 갱신 워크플로 미배포**: `.github/workflows/update-steam-data.yml` 은 로컬에만 있고 **git에 커밋하지 않음**(untracked). 이유: `gh` 토큰에 `workflow` 권한이 없어 push 하면 거부됨. 올리려면 사용자가 `gh auth refresh -s workflow`(브라우저 인증) 후 커밋·push. 그 전까지 `data/steam`은 `node scripts/fetch-steam.mjs`를 직접 실행해 갱신하고 커밋해야 함
- **(참고) 배포 전 알아둘 것**: (1) 워크플로 파일을 push하려면 GitHub 토큰에 `workflow` 권한이 필요함 — 현재 `gh` 토큰엔 없음 → 배포 시 `gh auth refresh -s workflow`(사용자가 브라우저 인증) 필요, 아니면 워크플로 파일만 빼고 push. (2) GitHub Actions 가 만든 커밋으로 Pages가 다시 빌드되는지는 **첫 실행 후 확인 필요**(미검증). (3) `file://`로 열면 `data/steam` 읽기가 막혀 예전 방식으로 보임 — 확인은 `python -m http.server`로. (4) 자동 갱신 대상은 갱신 시점의 CheapShark 목록이라, 그 사이 메인에 새로 뜨는 게임은 파일이 없을 수 있음(그 경우 기존 방식으로 표시)
