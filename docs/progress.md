## 7차: 임팩트 모션 (포트폴리오용으로 단조로워 보여서 추가)

- **Hero**: 마우스 움직임에 배경 이미지·장식(궤도/SALE·TOP 글자)·텍스트가 서로 다른 속도로 움직이는 시차 + 커서를 따라다니는 은은한 빛
- **카드**: 인기/최신/대표할인 카드가 마우스 위치에 따라 기울어지고(최대 4~7도) 빛이 반사됨. 가로형 할인 카드는 제외
- **스크롤**: 섹션이 보이면 카드가 90ms 간격으로 순서대로 올라오며 등장
- **숫자**: 대표 할인 카드의 `-50%`가 0부터 올라감 (0.9초)
- 마우스 전용(`hover:hover` + `pointer:fine`)이고 `prefers-reduced-motion` 이면 모두 꺼짐 → 터치 기기·모션 줄이기에서는 기존 화면 그대로
- 검증: Chrome 원격제어로 실제 마우스 이동 → `--px`, 틸트 `--rx/--ry`, 카운트업(-33% → -50%) 값 확인, 1440px/390px 레이아웃 확인

## 16차: Steam 상세 정보 미리 받아 저장 (2026-11-15, 배포됨 `6da54db`)

- **문제**: Steam 유료 게임은 상세 페이지에 소개·스크린샷·요구사항이 없었음. Steam API(`store.steampowered.com/api/appdetails`)는 데이터는 주지만 CORS 헤더가 없어 **브라우저가 직접 못 읽음**(서버에서는 정상)
- **해결**: 미리 받아서 파일로 저장 → 같은 사이트 파일이라 CORS 문제 없음
  - `scripts/fetch-steam.mjs`(Node 18+, 패키지 없음): CheapShark 인기 12·최신 12·할인 10 + 편집 선정 국내 5개 = 약 39개를 `l=koreana&cc=kr`로 받아 `data/steam/<appId>.json`(+`index.json`)에 저장. 요청 사이 1.5초 대기, 실패는 건너뜀, 대상에서 빠진 파일은 삭제. 저장 항목: 이름·설명(`descLang` ko/en)·장르·개발사·퍼블리셔·스크린샷(thumb/full 8장)·최소 요구사항(항목명 한국어)·한국어 지원 여부
  - **실행 결과**: 39개 중 35개 저장(약 209KB). **로스트아크·검은사막·메이플스토리·던전앤파이터는 Steam이 한국 지역에서 정보를 주지 않아 파일 없음**(한국 퍼블리셔 직접 서비스) → 직접 쓴 한국어 소개로 대체
  - `game-service.js`: `getSteamStatic(appId)`로 파일을 읽음. **없으면 예전 방식으로 그대로 표시**(안전). 소개 우선순위 = 직접 쓴 한국어 > Steam 설명(한국어/영문) > FreeToGame 영문. 스크린샷·개발사·퍼블리셔·요구사항·장르도 Steam 데이터 우선, 스크린샷은 `{thumb, full}` 형태로 통일
  - `game-detail.js`: 소개 출처 문구 세분화(직접 작성 / Steam 한국어 / Steam 영문 / FreeToGame), 영문이면 번역 버튼, 게임 정보에 '한국어 지원' 행, **Steam 스토어 위젯은 맨 아래로**('Steam 스토어')
  - `.github/workflows/update-steam-data.yml`: 매일 04:17(KST) 자동 실행 + 수동 실행 가능, 변경되면 `data/steam`만 커밋·push
- 결과 예: Baldur's Gate 3(영문 소개+번역 버튼, 스크린샷 8, 요구사항 7), ELDEN RING(한국어 소개), PUBG(직접 쓴 소개+Steam 스크린샷)
- **자동 갱신 워크플로 미배포**: `.github/workflows/update-steam-data.yml` 은 로컬에만 있고 **git에 커밋하지 않음**(untracked). 이유: `gh` 토큰에 `workflow` 권한이 없어 push 하면 거부됨. 올리려면 사용자가 `gh auth refresh -s workflow`(브라우저 인증) 후 커밋·push. 그 전까지 `data/steam`은 `node scripts/fetch-steam.mjs`를 직접 실행해 갱신하고 커밋해야 함
